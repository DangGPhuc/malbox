# MALBOX-AI v0.2 — Ghidra Function Explorer UI (Phase 3B)

The **Ghidra Function Explorer** gives malware analysts a structured, read-only browser interface for static PE disassembly metadata, selective decompiled C-like pseudocode, call relationships, imports, strings, cross-references, and heuristic triage candidates generated by Phase 3A.1 [`GhidraStaticAnalyzer`](../../backend/app/services/static_analysis/ghidra_adapter.py).

All static UI views strictly separate structural code discovery from executed runtime behavior and synthetic Replay telemetry.

---

## 1. Component & Navigation Architecture

- **Lazy Route Shell ([`App.tsx`](../../frontend/src/App.tsx)):**
  - `StaticAnalysisPage` is loaded on demand with `React.lazy(...)` + `<Suspense>` on `#static/<analysis_id>` or tab selection, keeping `cytoscape.esm` and static explorer panels split cleanly out of the main shell chunk.
  - Entry points are integrated into [`Navbar.tsx`](../../frontend/src/components/Navbar.tsx) (`Static Analysis`), [`WorkspacePage.tsx`](../../frontend/src/pages/WorkspacePage.tsx) (`Static Function Explorer`), and [`IntelligenceReportHeader.tsx`](../../frontend/src/components/IntelligenceReport/IntelligenceReportHeader.tsx).
- **Compact Intelligence Integration ([`StaticAnalysisSummaryCard.tsx`](../../frontend/src/components/IntelligenceReport/StaticAnalysisSummaryCard.tsx)):**
  - Embedded in [`ReportPage.tsx`](../../frontend/src/pages/ReportPage.tsx) using read-only `GET /api/v1/analyses/{id}/static-analysis` without disturbing Replay provenance banners or legacy reports (`intelligence_report: null`).
- **Workspace Modules ([`frontend/src/components/StaticAnalysis/`](../../frontend/src/components/StaticAnalysis/)):**
  1. `StaticTriggerBar.tsx`: Provenance & containment badges (`binary_executed: false`, `os_sandbox`, `memory_limit_backend`, `provenance_scope`), `Disabled by Config` notice when `MALBOX_GHIDRA_ENABLED=false`, bounded polling controls, and manual authorized trigger form.
  2. `FunctionExplorerPanel.tsx`: Searchable (`name`, `entry_address`, `function_id`, imported APIs, string IDs), sortable (`rank_score`, `size_bytes`, `xrefs`, `entry_address`, `name`), filterable (`Hide thunks`, `Hide external`, `Decompiled only`) table plus Selected Function Metadata and clickable caller/callee chips with graceful `[unindexed]` fallback notices.
  3. `DecompilerViewer.tsx`: Read-only pseudocode pane with mandatory `GHIDRA PSEUDOCODE — NOT ORIGINAL SOURCE CODE` badge, local-only indicator, line numbers, live in-code search highlight + match count, safe plain-text copy buttons, and explicit `TRUNCATED` / `TIMED_OUT` / `ERROR` / `SKIPPED_CAP` state alerts.
  4. `StaticCallGraphPanel.tsx`: Interactive bounded Cytoscape call relationship view (`Selected Neighborhood` vs `Bounded Overview`, zoom/fit controls, internal vs external import vs unresolved/omitted target styling, and keyboard-accessible semantic node/edge panel).
  5. `StaticArtifactsPanel.tsx`: Tabbed browser across Ranked Function Findings (with mandatory non-proof advisory disclaimers), Imports & Exports (with jump-to-caller chips), Static Strings, and Cross-References.

## 2. Safety, Security & Provenance Controls

1. **Zero Automatic Execution on Mount:**
   - Mounting `StaticAnalysisPage` or `ReportPage` invokes read-only `GET` endpoints only. Neither UI view automatically posts to `POST /api/v1/analyses/{id}/static-analysis` or spawns Ghidra.
2. **Ephemeral In-Memory Authorization Token:**
   - Queueing `POST /api/v1/analyses/{id}/static-analysis` requires explicit analyst submission and passes `X-Reporting-Token` strictly in transient component state (`React.useState`). The token is never persisted in `localStorage`, `sessionStorage`, query parameters, or hash URLs.
3. **Resilient Error Handling & Bounded Polling:**
   - Polling (`2500ms`, capped at 120 ticks) runs only for active jobs (`PENDING`, `QUEUED`, `RUNNING`) and cleans up automatically on terminal statuses (`COMPLETED`, `PARTIAL`, `FAILED`, `TIMED_OUT`, `UNAVAILABLE`, `SKIPPED`) or unmount.
   - HTTP `401`, `403`, `409`, and `503` responses display actionable containment/authorization diagnostics while keeping prior loaded functions and pseudocode intact.
4. **XSS-Safe Plain-Text Pseudocode & Symbol Rendering:**
   - [`tokenizePseudocodeLine`](../../frontend/src/components/StaticAnalysis/utils.ts) renders recovered pseudocode inside React text spans—never `dangerouslySetInnerHTML`, `innerHTML`, or eval—preventing script injection from binary symbols, strings, or comments.
5. **Non-Execution Epistemic Discipline:**
   - All function rows and detail panels mark static symbols as structural discoveries (`is_executed: false`, `binary_executed: false`). Disassembled functions, imports, or heuristic rank scores never assert executed runtime behavior or proven malicious intent.
6. **Bounded Call Graph Rendering:**
   - `buildBoundedCallGraph` enforces frontend caps of `MAX_STATIC_GRAPH_NODES = 60` and `MAX_STATIC_GRAPH_EDGES = 100` alongside explicit truncation/unresolved target counters so large PE binaries remain responsive inside a ~8 GB Kali VM.
